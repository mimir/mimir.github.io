9/// An RWPhase that lifts direct-style calls of CPS functions out of the bodies of continuations.
10///
11/// A subclass calls lift() for a call `k arg` of a CPS `k: Cn [T, Cn U]` while rewriting a continuation's body.
12/// It allocates a fresh continuation `cont` receiving the result and records the pending call `k (arg, cont)`;
13/// `cont`'s variable is the value of the call.
14/// Once the enclosing Lam is done, the pending calls are wired up in encounter order.
15/// This respects data dependencies, because operands are always rewritten before their users:
16/// ```
17/// lam = k₀ (arg₀, cont₀)
18/// cont₀ = k₁ (arg₁, cont₁)
19/// ...
20/// contₙ = rewritten body of lam
21/// ```
22/// A lifted call simply lives in the Lam whose body rewriting first reaches it.
23/// Rewrites whose result mentions such a continuation variable are scoped to that Lam.
24/// Sibling scopes re-derive - and thus re-lift - them.
25class DS2CPS : public RWPhase {
26public:
27 using RWPhase::RWPhase;
28 ~DS2CPS() override {
29 assert((std::uncaught_exceptions() || pending_.empty()) && "a call lifted outside of any Lam is never wired");
30 }
31
32protected:
