Detailed Description

Rebuilds old_world() into new_world() and then swaps them.

It is a Phase and a Rewriter that runs an optional analyze() to a fixed point. Then, it rewrites all old World::externals(). An World::Annexes::opaque() annex is not rewritten but resolved to the annex of the same flags in new_world().

If an associated Analysis is provided, the rewrite can query its abstract results through lattice().

Note
You can override
  • Rewriter::rewrite(),
  • Rewriter::rewrite_imm(),
  • Rewriter::rewrite_mut(), etc.
