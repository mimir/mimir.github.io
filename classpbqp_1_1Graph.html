Detailed Description

A PBQP problem graph.

Every node carries a cost vector with one entry per option. Every edge carries a cost matrix indexed by the options of its endpoints: 

matrix[src_option, dst_option]

The total cost of an assignment x is 

sum_n c_n(x_n) + sum_{mn} M_mn(x_m, x_n)

A node holds at most one edge to any other node, so parallel edges have to be merged by summing their matrices first. A Graph only grows; ids are handed out consecutively from 0.
