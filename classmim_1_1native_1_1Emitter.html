Detailed Description

Writes the GNU assembler code of one function on the registers that Color assigned.

The control flow is target-independent: jumps, calls, returns, and the entry are parallel copies, the blocks are laid out by layout(), and the callee-saved registers that hold values are saved. A backend derives from it and emits its instructions, moves, branches, prologue, and epilogue.
