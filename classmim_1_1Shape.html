Detailed Description

The extents of a Seq's axes: a plain Nat for a single axis, an aggregate of them for several.

A multi-dimensional index into a Seq has the very same structure - one component per axis, Idx instead of Nat - so it uses this view as well.

Note
A Shape is a non-owning view over a Def and may be null; Shape::operator* hands the Def back.
