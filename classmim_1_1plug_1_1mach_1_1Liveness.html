Detailed Description

Liveness of the values of one scheduled function, as a side table.

A value is a non-memory result of an instruction on a mem.M 0 chain or a non-memory parameter. A parameter is defined at the entry of its block and a jump uses its arguments, so a parameter is never live-in. A branch on a condition code uses its flags; the Bool is a value only if something else uses it.
