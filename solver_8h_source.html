50/// Heuristic PBQP solver.
51///
52/// Reduces degree 0, 1 (RI) and 2 (RII) nodes exactly and higher-degree nodes with the RN heuristic.
53/// Normalization keeps intermediate costs relative, so they saturate only where option costs differ by Cost::inf.
54/// Short of that, the result is optimal whenever no RN step is needed, e.g. on trees.
55/// RN decides the node with the highest `rn_priority[n]` first; ties go to the highest degree, then the widest cost
56/// spread. SSA-based register allocation passes PEO positions, so coloring cannot fail (Buchwald et al. 2011). Requires
57/// `rn_priority` to be empty or to cover every node id.
58[[nodiscard]] Solution solve(const Graph& graph, fe::View<size_t> rn_priority = {});
