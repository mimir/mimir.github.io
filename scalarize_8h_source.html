11/// Scalarization (= argument simplification):
12/// ```
13/// f := λ (x_1: [T_1, T_2], .., x_n: T_n).E
14/// ```
15/// becomes
16/// ```
17/// f' := λ (y_1: T_1, y_2: T_2, .. y_n: T_n).E[x_1 \ (y_1, y_2); ..; x_n \ y_n]
18/// ```
19/// It is type-directed: an immutable `Cn` is flattened along with all its Lam%s and App%s, even escaping ones.
20/// A flattened value is coerce()d where it meets an unflattened shape, e.g. an Axm's signature.
21/// An Axm handed a bare function (`autodiff.ad f`) is instantiated with the old shape, as its type may rely on it.
22/// A Pi is pinned where a coercion would be observable:
23/// * a `Cn` an interface Lam's signature reaches through a type coerce() cannot take apart (`mem.Ptr0 K`), or
24/// * a parameter indexed non-constantly or consumed whole by an Axm - only this parameter is kept.
25///
26/// Each run flattens one level; the fixed-point pipeline repeats it.
27/// Flags::scalarize_threshold bounds which Arr%s are expanded.
