10/// Perform Scalarization (= Argument simplification).
11/// This means that, e.g.,
12/// ```
13/// f := λ (x_1: [T_1, T_2], .., x_n: T_n).E
14/// ```
15/// will be transformed to
16/// ```
17/// f' := λ (y_1: T_1, y_2: T_2, .. y_n: T_n).E[x_1 \ (y_1, y_2); ..; x_n \ y_n]
18/// ```
19/// if `f` appears in callee position only (see @p EtaExp).
20///
21/// The phase flattens **one level** of a lambda's (thresholded) parameters per run.
22/// Because it is scheduled inside a fixed-point pipeline (`%compile.phases tt (...)`),
23/// re-running it converges to a full flatten; each run that peels calls invalidate().
24///
25/// Flattening respects Flags::scalarize_threshold via the thresholded projection helpers
26/// (Def::num_tprojs, Lam::tvar, App::targ): a parameter is only expanded if its arity is
27/// below the threshold.
28/// It will not flatten mutable @p Sigma%s or @p Arr%ays (their vars have no static arity).
29///
30/// A parameter that is @p Extract%ed / @p Insert%ed via a **non-constant** index is left
31/// intact: splitting it would only force the body to reassemble the tuple.
32class Scalarize : public RWPhase {
33private:
34 /// Optimistic fixed-point analysis: every optimizable @p Lam is assumed splittable
35 /// until proven otherwise (escape, branch/dispatch tuple disagreement, or a
36 /// dynamically-indexed parameter).
37 class Analysis : public mim::Analysis {

44 /// Cheap; recomputed on demand from the (post-fixed-point) demote/lock state.
45 Vector<bool> plan(Lam* lam);
