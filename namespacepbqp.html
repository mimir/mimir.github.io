◆ read_json()

void pbqp::read_json ( std::istream & in,
Instance & instance,
const std::filesystem::path & path = "<input>" )

Read a PBQP instance into the empty instance: 

{
  "nodes": [{"costs": [0, "inf"]}, {"costs": [7, 0, 2]}],
  "edges": [{"src": 1, "dst": 0, "rows": 3, "cols": 2, "costs": [1, "inf", -5, 0, 4, 2]}],
  "rn_priority": [5, 9]
}

The position of a node in nodes is its id. Edge costs are row-major with src as the row; rows and cols are optional and only checked. "inf" is Cost::inf, rn_priority is optional, and unknown keys are skipped. Throws fe::Error::Bail, a std::exception, on malformed input; path only names the input in its message.

◆ solve()

Solution pbqp::solve ( const Graph & graph,
fe::View< size_t > rn_priority = {} )
nodiscard

Heuristic PBQP solver.

Reduces degree 0, 1 (RI) and 2 (RII) nodes exactly and higher-degree nodes with the RN heuristic. Normalization keeps intermediate costs relative, so they saturate only where option costs differ by Cost::inf. Short of that, the result is optimal whenever no RN step is needed, e.g. on trees. RN decides the node with the highest rn_priority[n] first; ties go to the highest degree, then the widest cost spread. SSA-based register allocation passes PEO positions, so coloring cannot fail (Buchwald et al. 2011). Requires rn_priority to be empty or to cover every node id.
