Detailed Description

Determines which allocations stay within the scope that allocates them.

The home of an allocation is the Lam on whose memory chain it sits. An allocation escapes if it flows into the data of a tail call - returned, or handed to a callee or continuation - or if an escaping Lam mentions it. Any op but mem.load, the address of a mem.store, and a mem.free of the allocation itself may retain the pointers it is handed, so they escape there. A Lam escapes if its use is unknown - it is used as a value - or if an escaping Lam jumps to it. An axiom in control position is assumed to only pass control on to the continuations it receives.

A buffer-typed parameter of a Lam takes on the value its known call sites pass, as in SCCP. An external Lam has unknown call sites, so whatever is passed to it escapes. A value only flows into a Lam that its scope strictly encloses; otherwise it would outlive its scope and escapes.

Lattice: an escaping allocation is ⊤ - keep as is; absent means it stays local. A parameter is ⊤ if its call sites disagree; everything they pass escapes.
