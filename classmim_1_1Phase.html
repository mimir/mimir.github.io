Detailed Description

A Phase performs one self-contained task over the whole World.

Phases are intended to run in a classical sequence, one after another.

◆ taint()

void mim::Phase::taint ( Def * mut)
inline

Marks mut as needs a (re)visit: sets Def::is_dirty() and records mut in dirty().

Whoever visits mut clears the bit again; a recorded mut whose bit is already clear is stale (it got its visit in the meantime) and is simply skipped by consumers.
