11/// Determines which allocations stay within the scope that allocates them.
12///
13/// The *home* of an allocation is the Lam on whose memory chain it sits.
14/// An allocation *escapes* if it flows into the data of a tail call - returned, or handed to a callee or continuation -
15/// or if an escaping Lam mentions it.
16/// Any op but `mem.load`, the address of a `mem.store`, and a `mem.free` of the allocation itself may retain the
17/// pointers it is handed, so they escape there. A Lam escapes if its use is *unknown* - it is used as a value - or if
18/// an escaping Lam jumps to it. An axiom in control position is assumed to only pass control on to the continuations it
19/// receives.
20///
21/// A buffer-typed parameter of a Lam takes on the value its known call sites pass, as in SCCP.
22/// An external Lam has unknown call sites, so whatever is passed to it escapes.
23/// A value only flows into a Lam that its scope strictly encloses; otherwise it would outlive its scope and escapes.
24///
25/// Lattice: an escaping allocation is ⊤ - keep as is; *absent* means it stays local.
26/// A parameter is ⊤ if its call sites disagree; everything they pass escapes.
27class EscapeAnalysis : public mim::Analysis {

33 DefVec targets; ///< The continuations the tail transfers control to.
34 };
