The x86_isel Plugin

See also
mim::plug::x86_isel

The instruction-selection rules of the x86 backend. gen writes them as C++ that the x86 plugin compiles in, so the compiler itself never loads this plugin.

Dependencies

plugin core;
plugin math;
import compile;
import mem;
import x86;

Guards

A guard is tt after instantiation or a conjunction of these atoms on meta variables.

imm

A literal that fits a sign-extended 32-bit immediate; stuck on anything but a literal.

axm imm: {s: Nat} → Idx s → Bool, normalize_imm;

lit

A literal.

axm lit: {T: *} → T → Bool, normalize_lit;

Operands

addr

The pointer p, an I64 under the cast of x86.legalize, as an address operand. isel picks its form, x86.Base or x86.Index, and the builder infers which.

axm addr: {T: *, a: Nat} → mem.Ptr (T, a) → x86.Base;

reg_imm

The operand x in a register or, if it is a literal that fits, as a sign-extended 32-bit immediate.

axm reg_imm: {s: Nat} → Idx s → Idx s;

reg_sh

The shift count x in a register or, if it is a literal, as an immediate, since x86 masks it.

axm reg_sh: {s: Nat} → Idx s → Idx s;

scaled

The I64 i as an index with its scale.

axm scaled: I64 → [I64, I2];

Commutativity

The operations whose two operands a rule also matches swapped.

anx let commutes = (core.wrap.add, core.wrap.mul, math.arith.add, math.arith.mul, core.bit2.and, core.bit2.or, core.bit2.xor, core.bit2.nand, core.bit2.nor, core.bit2.nxor);

Rules

Each family takes the operand size as {s: Nat}, which gen instantiates at each of sizes that the refly.checks of its instructions and its guard admit. A meta variable that the right-hand side uses and no other meta variable's type mentions is an operand, unless it is a memory. An lhs (m, e) replaces e and, by the memory of the rhs, the memory m of an inner node of e. A family that takes a marker r puts its second operand under reg_imm or reg_sh. c is the size of what the instruction yields, which the frontend cannot infer.

let mark = {s: Nat} → Idx s → Idx s;

ALU

rule alu (c: Nat → Nat) (op: Nat → {s: Nat} → «2; Idx s» → Idx s, insn: {s: Nat} → «2; Idx s» → Idx (c s)) (r: mark) {s: Nat} (m: Nat, a b: Idx s): op m (a, b) => insn (a, r b);
rule shift (op: {s: Nat} → «2; Idx s» → Idx s, insn: {s: Nat} → «2; Idx s» → Idx (x86.gpr s)) (r: mark) {s: Nat} ( a b: Idx s): op (a, b) => insn (a, r b);
rule neg (op: Nat → {s: Nat} → «2; Idx s» → Idx s, insn: {s: Nat} → «2; Idx s» → Idx (x86.logic s)) (r: mark) {s: Nat} (m: Nat, a b: Idx s): op m (a, b) => let x = insn (a, r b); x86.xor (x, core.bit1.t 0 x);
rule mul8 (m: Nat, a b: I8): core.wrap.mul m (a, b) => x86.trunc i8 (x86.imul (x86.movzx i32 a, x86.movzx i32 (reg_imm b)));

Division

div and idiv yield both the quotient and the remainder at i; they have no 8-bit form, so i8 widens to i32 by ext. core.rem puts its divisor into a register with x86.mov, whose result type only folds for a literal size.

rule div (op: {s a: Nat} → [mem.M a, «2; Idx s»] → [mem.M a, Idx s], insn: {s: Nat} → «2; Idx s» → «2; Idx (x86.gpr16 s)», i: Idx 2) {s: Nat} (m: mem.M 0, a b: Idx s): op (m, (a, b)) => (m, (insn (a, b))#i);
rule div8 (op: {s a: Nat} → [mem.M a, «2; Idx s»] → [mem.M a, Idx s], insn: {s: Nat} → «2; Idx s» → «2; Idx (x86.gpr16 s)», i: Idx 2, ext: {s: Nat} → [d: Nat] → Idx s → Idx d) (m: mem.M 0, a b: I8 ): op (m, (a, b)) => (m, x86.trunc i8 (insn (ext i32 a, ext i32 b))#i);
rule rem8 (d: Nat, x: I8): core.rem d x => x86.trunc i8 (x86.div (x86.movzx i32 x, x86.mov (core.idx 0 i32 d)))#1_2;
rule rem16 (d: Nat, x: I16): core.rem d x => (x86.div (x, x86.mov (core.idx 0 i16 d)))#1_2;
rule rem32 (d: Nat, x: I32): core.rem d x => (x86.div (x, x86.mov (core.idx 0 i32 d)))#1_2;
rule rem64 (d: Nat, x: I64): core.rem d x => (x86.div (x, x86.mov (core.idx 0 i64 d)))#1_2;

Conversions

mem.legalize_ptr and x86.legalize leave only register sizes; each family takes the source and the destination size. A conversion between sizes of the same register width truncates; rank is the register width of a size.

lam rank (s: Nat): Nat = (((1, 2)#(core.ncmp.e (s, i16)), 3)#(core.ncmp.e (s, i32)), 4)#(core.ncmp.e (s, i64));
lam narrows (s d: Nat): Bool = core.bit2.and 0 (core.ncmp.ne (s, d), core.ncmp.le (rank d, rank s));
lam widens (s d: Nat): Bool = core.ncmp.l (rank s, rank d);
rule trunc {s: Nat} {d: Nat} (x: Idx s): core.conv.u d x when narrows (s, d) => x86.trunc d x;
rule strunc {s: Nat} {d: Nat} (x: Idx s): core.conv.s d x when narrows (s, d) => x86.trunc d x;
rule zext {s: Nat} {d: Nat} (x: Idx s): core.conv.u d x when widens (s, d) => x86.movzx d x;
rule sext {s: Nat} {d: Nat} (x: Idx s): core.conv.s d x when widens (s, d) => x86.movsx d x;
rule cast_trunc {s: Nat} {d: Nat} (x: Idx s): core.bitcast (Idx d) x when narrows (s, d) => x86.trunc d x;
rule cast_zext {s: Nat} {d: Nat} (x: Idx s): core.bitcast (Idx d) x when widens (s, d) => x86.movzx d x;

Comparisons

Each family takes the predicate and its condition code.

rule icmp (p: {s: Nat} → «2; Idx s» → Bool, c: x86.Flags → Bool) (s: Nat, a b: Idx s): p (a, b) => c (x86.cmp (a, reg_imm b));

Selects

x86.cmovcc's normalizer fuses a condition code into it; i8 and Bool, which it has no form for, go through i32.

rule select {s: Nat} (x y: Idx s, c: Bool): (x, y)#c => x86.cmovcc.ne (x86.test (c, c), x, y);
rule select8 {s: Nat} (x y: Idx s, c: Bool): (x, y)#c when core.bit2.or 0 (core.ncmp.e (s, i1), core.ncmp.e (s, i8)) => x86.trunc s (x86.cmovcc.ne (x86.test (c, c), x86.movzx i32 x, x86.movzx i32 y));

Floating Point

Float instructions work on math.F pe values in XMM registers. A family takes the format as {pe: «2; Nat»}, which gen instantiates at each of formats that the x86.fpe or x86.fok in its rule's type admits. f2f takes both formats explicitly, since one of the same format would convert a float to itself. A family op with an insn maps a math operation onto an x86 instruction, rm folds a sole load into its source, and swap takes the converse predicate.

pub mod float
let Op1 = Nat → {pe: «2; Nat»} → math.F pe → math.F pe;
let Op2 = Nat → {pe: «2; Nat»} → «2; math.F pe» → math.F pe;
let Pred = Nat → {pe: «2; Nat»} → «2; math.F pe» → Bool;
let Insn1 = {pe: «2; Nat»} → math.F pe → math.F (x86.fpe pe);
let Insn2 = {pe: «2; Nat»} → «2; math.F pe» → math.F (x86.fpe pe);
let Cmp = {pe: «2; Nat»} → «2; math.F pe» → Idx (x86.fok pe 2);

Comparisons

ucomiss compares its register operand to its source, which may be a load.

swap takes the converse predicate, so that setcc already gets the unordered case right.

rule cmp (op: Pred, c: Cmp) {pe: «2; Nat»} (k: Nat, a b: math.F pe): op k (a, b) => c (a, b);
rule swap (op: Pred, c: Cmp) {pe: «2; Nat»} (k: Nat, a b: math.F pe): op k (a, b) => c (b, a);
rule cmp_rm (op: Pred, c: Cmp) {pe: «2; Nat»} (k: Nat, a: math.F pe, m: mem.M 0, p: mem.Ptr0 (math.F pe)): let (mm, v) = mem.load (m, p); (mm, op k (a, v)) => x86.rm c (m, a, addr p);
rule swap_rm (op: Pred, c: Cmp) {pe: «2; Nat»} (k: Nat, a: math.F pe, m: mem.M 0, p: mem.Ptr0 (math.F pe)): let (mm, v) = mem.load (m, p); (mm, op k (v, a)) => x86.rm c (m, a, addr p);

cmps folds a load into the second operand, swaps into the first via the converse, and syms of a symmetric predicate into either.

lam cmps (op: Pred, c: Cmp) = (cmp (op, c), cmp_rm (op, c));
lam swaps (op: Pred, c: Cmp) = (swap (op, c), swap_rm (op, c));
lam syms (op: Pred, c: Cmp) = (cmps (op, c), swap_rm (op, c));
anx let comparisons = (
syms (math.cmp.e, x86.fcmp.e), syms (math.cmp.ne, x86.fcmp.ne), syms (math.cmp.o, x86.fcmp.o),
syms (math.cmp.u, x86.fcmp.u), syms (math.cmp.ue, x86.fcmp.ue), syms (math.cmp.une, x86.fcmp.une),
cmps (math.cmp.g, x86.fcmp.g), cmps (math.cmp.ge, x86.fcmp.ge),
cmps (math.cmp.ul, x86.fcmp.ul), cmps (math.cmp.ule, x86.fcmp.ule),
swaps (math.cmp.l, x86.fcmp.g), swaps (math.cmp.le, x86.fcmp.ge),

Conversions

The integer size is a family parameter, since neither side determines it.

A float of the same format converts to itself, so f2f only has the two mixed pairs.

u2f and f2u have only the i32 form: not every u64 is an exact f64; u2f reads its operand twice, so it folds no load.

rule s2f (s: Nat) {pe: «2; Nat»} (x: Idx s): math.conv.s2f pe x => x86.i2f s pe x;
rule u2f (s: Nat) {pe: «2; Nat»} (x: Idx s): math.conv.u2f pe x => x86.u2f s pe x;
rule f2s (s: Nat) {pe: «2; Nat»} (x: math.F pe): math.conv.f2s s x => x86.f2i pe s x;
rule f2u (s: Nat) {pe: «2; Nat»} (x: math.F pe): math.conv.f2u s x => x86.f2u pe s x;
rule f2f (spe: «2; Nat», dpe: «2; Nat») (x: math.F spe): math.conv.f2f dpe x => x86.f2f spe dpe x;
rule s2f_rm (s: Nat) {pe: «2; Nat»} (m: mem.M 0, p: mem.Ptr0 (Idx s)): let (mm, v) = mem.load (m, p); (mm, math.conv.s2f pe v) => x86.rm1 (x86.i2f s pe) (m, addr p);
rule f2s_rm (s: Nat) {pe: «2; Nat»} (m: mem.M 0, p: mem.Ptr0 (math.F pe)): let (mm, v) = mem.load (m, p); (mm, math.conv.f2s s v) => x86.rm1 (x86.f2i pe s) (m, addr p);
rule f2u_rm (s: Nat) {pe: «2; Nat»} (m: mem.M 0, p: mem.Ptr0 (math.F pe)): let (mm, v) = mem.load (m, p); (mm, math.conv.f2u s v) => x86.rm1 (x86.f2u pe s) (m, addr p);
rule f2f_rm (spe: «2; Nat», dpe: «2; Nat») (m: mem.M 0, p: mem.Ptr0 (math.F spe)): let (mm, v) = mem.load (m, p); (mm, math.conv.f2f dpe v) => x86.rm1 (x86.f2f spe dpe) (m, addr p);

Loads and Stores

A pointer is an I64 by now, which x86.legalize casts to the pointer type of each memory operation.

rule load {s: Nat} (m: mem.M 0, p: mem.Ptr0 (Idx s)): mem.load (m, p) => x86.load s (m, addr p);
rule store (s: Nat, m: mem.M 0, p: mem.Ptr0 (Idx s), x: Idx s): mem.store (m, p, x) => x86.store (m, addr p, reg_imm x);

Memory Operands

op r, m folds a load into the second operand; op m, r also stores to the address it loads from. Either takes only a size that x86.load takes.

rule rm (c: Nat → Nat) (op: Nat → {s: Nat} → «2; Idx s» → Idx s, insn: {s: Nat} → «2; Idx s» → Idx (c s)) {s: Nat} (k: Nat, a: Idx s, m: mem.M 0, p: mem.Ptr0 (Idx s)): let (mm, v) = mem.load (m, p); (mm, op k (a, v)) when x86.is_gpr s => x86.rm insn (m, a, addr p);
rule mr (c: Nat → Nat) (op: Nat → {s: Nat} → «2; Idx s» → Idx s, insn: {s: Nat} → «2; Idx s» → Idx (c s)) {s: Nat} (k: Nat, b: Idx s, m: mem.M 0, p: mem.Ptr0 (Idx s)): let (mm, v) = mem.load (m, p); mem.store (mm, p, op k (v, b)) when x86.is_gpr s => x86.mr (insn @ s) (m, addr p, reg_imm b);

Addresses

A product with 2, 4, or 8, or a left shift by 1, 2, or 3, is an index with its scale; an address takes any index as one, scaled by 1 if need be. Of two matches that cost the same, isel keeps the first, so larger patterns come first. The core.wrap.add normalizer pulls a literal out of a nested sum, so a displacement sits outermost.

rule scale (op: Nat → {s: Nat} → «2; Idx s» → Idx s, k: I64, sc: I2) (n: Nat, i: I64): op n (i, k) => (i, sc);

Non-Terminals

A rule whose lhs is all of its meta variables converts between non-terminals; isel chains them. x86.addr and x86.lea normalize away what a literal makes trivial. A literal converts by x86_isel.lit: into an absolute address for free, else into a register first; the builder of mov takes any size.

rule base (x: I64): x => x86.addr (0I32, x);
rule abs (x: I64): x when lit x => x86.addr (0I32, x);
rule mov (x: I64): x when lit x => x86.mov x;
rule fmov (pe: «2; Nat») (x: math.F pe): x when lit x => x86.fmov x;
rule lea (i: Bool) (a: x86.Addr i): a => x86.lea a;
rule scale1 (i: I64): i => (i, x86.scale_1);
rule unscale (s: [I64, I2]): s => x86.lea (x86.index (x86.addr (0I32, 0I64)) s);
