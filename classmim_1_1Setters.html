Detailed Description

template<class P, class D = Def>
class mim::Setters< P, D >

CRTP-based mixin to declare setters for Def::loc & Def::name using a covariant return type.

Forwards every argument list the Def::setters accept and hands back a P instead of a Def.

Note
Setters::Fwd keeps this variadic out of the overload set of the set members subclasses declare themselves (Global::set, Pi::set, ...) - none of those is a template on Ow, so they keep winning.
