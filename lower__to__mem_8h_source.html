43 /// A `⊥: mem.M 0` placeholder consumed by emitted buffer operations; AddMem replaces it with the
44 /// scheduler-placed current memory.
45 /// Shared by every op whose result is a pure function of its value operands, so that genuinely equal
46 /// ops still collapse into one (e.g. a weight literal materialized at many sites).
47 const Def* bot_mem();
48
49 /// A *fresh* `mem.M 0` for one emitted buffer/btensor operation: the var of a newly minted continuation
50 /// `con fresh_mem(mem: mem.M 0)` that receives its memory once LowerToMem::wrap_fresh_mem has chained it
51 /// in front of the enclosing lam's body.
52 /// Required by every op that allocates a buffer it then writes into, for two independent reasons:
53 /// 1. Immutable Def%s are hash-consed, so two `buffer.alloc`s agreeing on `(r, s, T)` and sharing one
54 /// placeholder collapse into a single allocation - two distinct tensors would alias one buffer.
55 /// 2. AddMem is a memoizing Rewriter, so two operations sharing one argument tuple
56 /// `(⊥: mem.M 0, …)` - which happens whenever they differ only in their curried callee - are threaded
57 /// from the *same* current memory, and the resulting parallel mem chains collapse in `cps.conv`.
58 /// Mutables are never hash-consed, so the continuations' vars are distinct by construction - no
59 /// distinguishing tag required.
60 const Def* fresh_mem();
61
62 /// Chains the LowerToMem::pending_ continuations in front of the freshly rewritten @p body:
63 /// yields `mem.fresh (0, k₁)` with `k₁ ↦ mem.fresh (0, k₂)`, …, and the last one carries @p body.
64 /// AddMem resolves each request by jumping to the continuation with the scheduler-placed current memory,
65 /// and the `tt` filter beta-reduces the continuations away again as soon as that happens.
66 const Def* wrap_fresh_mem(const Def* body);
