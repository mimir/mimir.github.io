9/// Bufferizes the low-level tensor axioms onto the shared `buffer` layer.
10/// `get` / `set` become `%buffer.read` / `%buffer.write`, `map_reduce` / `broadcast` / `pad` / `concat`
11/// become their buffer-world `%btensor.*` counterparts,
12/// and tensor array values `«s; T»` become `%buffer.Buf (r, s, T)` handles.
13/// Afterwards `%buffer.lower_ptr` lowers the buffer layer to `%mem.Ptr` + `%mem.lea` / `%mem.load` / `%mem.store`.
14///
15/// This phase is *conversion-only*: it rewrites types and operations but does not thread the `%mem.M`
16/// memory monad itself. Emitted buffer operations consume a `⊥: %mem.M 0` placeholder (or a short local
17/// chain rooted in a LowerToMem::fresh_mem continuation's var), and the SSA value dependencies keep them
18/// anchored and ordered. The `%mem.add_mem` phase
19/// (mim::plug::mem::phase::AddMem), scheduled right after this one in the pipeline, then mem-extends all
20/// continuations and rewires every memory operand to the scheduler-placed current memory — handling returns,
21/// error continuations, join points, branch arms, and interleaving with a caller's own memory operations
22/// uniformly.
23///
24/// Which array types denote tensors (as opposed to index/shape arrays that share the `Arr` structure) is
25/// determined by *role*: a pre-pass collects the array operand/result types of the tensor operations, and only
26/// those types are rewritten to `Buf` — and only at function boundaries, never as a global type rewrite.

93 /// in front of the enclosing lam's body.
